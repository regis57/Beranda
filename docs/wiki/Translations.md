# Translations

- **Display: 57 languages**, including Arabic, Hebrew, Persian and Urdu written right to left.
  Every language file must have all the keys of `en.json` (a test checks it); regional files
  (`pt-BR`, `zh-TW`) only override their base language.
- **Settings page: 9 languages**: English, French, German, Spanish, Italian, Portuguese (+ Brazilian),
  Indonesian, Arabic, Swahili. Other languages fall back to English.
- **Voice: 10 languages** with ready-made phrases (en, fr, de, es, it, pt, pt-BR, ar, sw, id);
  any language works for your own phrases.

All countries and languages: [docs/COUNTRIES.md](https://github.com/regis57/Beranda/blob/main/docs/COUNTRIES.md).
